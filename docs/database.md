# База данных

На текущем этапе структура базы данных еще не зафиксирована.

Перед реализацией необходимо сначала спроектировать сущности и связи между ними.

Предположительно будут существовать следующие сущности:

- Команда
- Пользователь
- Задача
- Граф задач
- Ответ
- Проверка ответа
- Чат
- Сообщение
- Диалог
- Персонаж
- Телефонный номер
- Звонок
- Этап сценария
- Администратор
- Настройки проекта

Требования:

- минимальное дублирование данных
- простота изменения структуры
- удобство ручного заполнения
- поддержка Supabase
- использование UUID там, где это имеет смысл

Необходимо предложить оптимальную структуру базы данных до начала реализации.
