# Зафиксированные решения

- **Реалтайм-обновления (задачи, чаты):** фронтенд подписывается напрямую на Supabase Realtime вместо polling через Flask. Бесплатный тариф Supabase это позволяет (до 200 одновременных realtime-подключений и 2 млн сообщений/мес — с большим запасом для одного квеста). Важный нюанс: бесплатные проекты Supabase приостанавливаются после недели неактивности — нужно будет заходить в проект периодически во время разработки и обязательно проверить/разбудить его перед самим мероприятием.
- **"Засыпание" Render на бесплатном тарифе:** решаем внешним пинг-сервисом, который будет регулярно дёргать сайт, чтобы инстанс не засыпал (конкретный сервис подберём на этапе деплоя).
