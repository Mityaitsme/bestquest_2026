# Quest Site

Сайт для проведения сюжетного городского квеста.

## Стек

- Python
- Flask
- Supabase
- Render
- GitHub

## Основные возможности

- система задач с ветвящимся графом
- сюжетные чаты
- интеграция с ChatGPT
- административная панель
- система проверки ответов
- эмуляция телефонных звонков

Подробная документация находится в папке docs.
